Tech Stack

ADA-Checker is built as a lightweight static web application using:



HTML – Provides the structure for the main application pages, including index.html, settings.html, and pricing.html.

CSS – Handles layout, typography, color, and responsive styling via stylesheets in the css/ directory.

JavaScript (vanilla JS) – Powers interactive behavior and UI logic using scripts in the js/ directory, without relying on a front-end framework.

SVG assets – Uses scalable vector graphics in the images/ directory for logos and icons to keep visuals sharp at any size.

Markdown – Documents the feature roadmap and accessibility rules in files like ada-roadmap.md.


This stack keeps the project simple to run and deploy (no backend required) while staying flexible enough to grow into a more advanced accessibility auditing tool over time.
